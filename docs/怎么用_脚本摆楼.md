## 一句话

在 Blender 脚本里调几个函数，跑完之后 **1 秒以内**，视效那台 live 编辑器（L_S02，CBD 那一格是 area_04_03）的画面就会更新，用户在 Selkies 上直接看。
同步只动“用哪个件、放在哪、怎么转、缩放多少、件本身的网格”这几样。材质、灯光、植被、后期都归 UE 管，同步不会碰它们。

## 什么时候能用

等协调通知“已接好”再开始。接好的意思是：视效编辑器加载了 L_S02、切到现在时代、对好 P1 机位，我已经 attach 了 area_04_03。
在那之前，脚本可以先写，也可以在我的测试编辑器上试跑。测试编辑器只是不出画面，功能一样，见本文最后一节。

## 最小例子（服务器上无界面运行，整个脚本约 0.3 秒）

```python
# cbd_radial.py   运行：blender -b --factory-startup --python cbd_radial.py
import math, sys
sys.path.insert(0, "/workspace/jobs/look-blsync-20261009-01/lib")
import renou_blsync_lib as rb

R = "/workspace/shared/eng-inst/u20b_r1/area_04_03/"
B = rb.Batch(R + "area_04_03_placements.json",
             out="/workspace/jobs/look-blsync-20261009-01/data/area_04_03_overrides.json",
             parts_glb=R + "area_04_03_parts.glb", load_meshes=False)   # 只读零件包围盒，不导网格

hub = B.centre(B.group("V10_TWR_000_BLD_HubTower_C1Empire"))         # 枢纽塔 C1 底面中心，约 (194.9, -394.3)
for key, n in B.srcs("CBDFILL"):                                       # 35 个 CBD 填充街块
    blk = B.group(key)
    c = B.centre(blk)
    face = math.degrees(math.atan2(c.y - hub.y, c.x - hub.x))          # 例子：朝向枢纽塔的方位角，按用户的规则替换
    B.rotate(blk, 15.0)                                                # 绕这栋楼自己的中心转（CCW，俯视）
    B.move(blk, (0.0, 0.0, -3.0 if c.x < hub.x else 3.0))              # 例子：左组略低、右组略高
r = B.publish("CBD radial v1")                                          # 写覆盖文件，等 UE 回执
print(r["rev"], r["ue"])                                                # UE 回执：counts、seconds、latency_s、errors
```

这个例子只是演示怎么调函数。摆放规则以用户定的为准：以枢纽塔为中心放射摆放，每栋转约 15°，左组略低，右组略高。

## 函数表（`renou_blsync_lib.py`，Blender 5.2，有界面、无界面都能用）

| 函数 | 作用 |
|---|---|
| `Batch(placements, out, parts_glb=None, load_meshes=True, only_src=None, remote=None, status=...)` | 载入一批，每个实例对应一个物体。`load_meshes=False`：不导网格，只从 GLB 头读每个零件的包围盒，最快，脚本摆楼用这个。`load_meshes=True`：真导网格，要在 Blender 里看模型或改网格时用，410 MB 的零件包约 18 秒。`only_src`：用正则只载一部分。 |
| `B.srcs("CBDFILL")` | 列出匹配的楼（src 里 ` \| ` 前面那段）和每栋的实例数。 |
| `B.group(key)` | 一栋楼的所有实例。key 是 building_id，或 src 里 ` \| ` 前面那段。 |
| `B.centre(objs, base=True)` | 楼的包围盒中心。`base=True` 时 z 取最低点（底面中心）。 |
| `B.move(objs, (dx, dy, dz))` | 平移，单位米，Blender 世界坐标。 |
| `B.rotate(objs, deg, centre=None)` | 绕竖轴转，默认绕楼自己的底面中心，即 M = T(c)·R·T(−c)。CBD 填充街块的网格按世界坐标烘焙、pos 是 0，所以必须用这个函数，不能直接改 rotation。 |
| `B.set_part(objs, part)` | 换件，换成本批已有的零件，或 `new_part` 新做的零件。 |
| `B.new_part(src_part, name)` / `B.export_part(part)` | 复制出一个新零件（需要 `load_meshes=True`）；改网格后只导出这一件，下次 `publish` 时 UE 约 1 秒换上，材质沿用 UE 的。 |
| `B.copy(objs, d)` / `B.delete(objs)` | 复制（新 id 自动生成）、删除。 |
| `B.reset(objs=None)` | 回到正式表。不传参数就是全部复位。复位后再 `publish` 一次，UE 也跟着复位。 |
| `B.publish(label)` | 把和正式表不同的地方全部写进覆盖文件（累计写，原子替换），等 UE 回执，最多等 30 秒。 |
| `B.write_back(out_dir)` | 定稿：生成 `<批>_placements_v<NNN>.json` 和 `<批>_changes_v<NNN>.md`，不覆盖任何已有文件。 |

坐标一律用 Blender 世界坐标，单位米，Z 朝上。四元数按 wxyz。旋转角度俯视逆时针为正。

## 规矩

1. **一批只有一个写入者。** 覆盖文件是累计的，两个脚本同时写同一批，后写的会把先写的改动冲掉。CBD 这一格（area_04_03）由工程独占，别的会话要改先和工程说好。
2. 每次运行都从正式表重新开始，所以脚本要一次把全部改动都做完再 `publish`。想在上一次的基础上接着改，就在同一个 Blender 进程里继续调函数、再 `publish`。
3. 不碰 `/workspace/shared/`，那是只读的正式版。覆盖文件只写到上面例子里的 `data/` 目录。
4. 回执的 `errors` 不为空就停下来看，常见原因是 part 名写错了。
5. 换成新零件、改网格，只在需要时用。材质会自动沿用 UE 已有的 MI_C_，槽名对不上的按 ct_placements 的规则套。Blender 里的材质不传，也不读。

## 用户点头以后：写回正式摆放表

```python
info = B.write_back("/workspace/jobs/<你的任务目录>/out")   # 生成新版摆放表和改动说明
```

1. 新版摆放表、改动说明，以及 `meshes/` 里改过的零件 GLB，交给工程按正常流程发布新版（比如 u20b_r2 的 area_04_03）。
2. 视效按新版重建这一层，重建前先对预览发 reset 或 detach。重建后用 attach 核对，误差必须是 0。
3. 覆盖文件作废，从新版开始。
